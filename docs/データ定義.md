# データ定義（`lib/constants.ts` に入れる値）

**この表の値をそのまま使ってください。** 項目名・時間・レイヤーのどれか1つでも変えると、
ほかの人と出力が一致しなくなります。順番もこのとおりに並べます。

- `useHours` … 「扱える」＝手を動かして成果物を出せる、までの標準学習時間
- `teachHours` … 「教えられる」＝なぜそれを選んだかを説明でき、人に教えられる、までの標準学習時間
- `layer` … その項目が求められ始めるレイヤー

## `teachHours` の決め方（参考）

`teachHours` は、レイヤーごとの倍率で `useHours` から置いた暫定値です（5時間単位に丸め）。
**表の値をそのまま使ってください。自分で計算し直さないこと**（丸めでズレます）。

| レイヤー | 倍率 |
| --- | ---: |
| 定型作業 | 1.5 倍 |
| 運用・保守 | 1.8 倍 |
| 構築 | 1.8 倍 |
| 設計 | 1.5 倍 |
| アーキテクト・リード | 1.3 倍 |

手順どおりの作業は教えるのが比較的やさしく、運用・構築は「なぜその構成か」を説明できるまでの差が大きい。
設計より上は、もともと説明そのものが仕事の中身なので差は小さい、という考え方です。
